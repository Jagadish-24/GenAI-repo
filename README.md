The Goal of this repo is to have version control of my RAG project

Used Nomic AI's `nomic-embed-text` via ollama to generate text embedding, Features of this text embedding model (source : gemini)
* Model Type	- Text Embedding / Feature Extraction
* Context Length - 	8,192 tokens (~6,000 words)
* Vector Dimension	- 768 dimensions (supports Matryoshka downsampling)
* Parameters - ~137 million parameters
* License	- Apache 2.0 (Fully open for commercial & personal use)
* Auditable / Reproducible - Fully open data, training code, and weights
